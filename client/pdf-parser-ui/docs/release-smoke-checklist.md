# Release smoke-checklist

Использовать после каждого релиза или перед демо.

## 1) Вход и сессия

- Открыть `/auth`, выполнить вход валидным пользователем.
- Проверить редирект в рабочую область и корректное отображение роли.
- Выполнить logout из верхнего меню и убедиться, что защищенные страницы недоступны.

## 2) Создание документа

- Перейти в `Все документы` -> `Создать документ`.
- Проверить обязательные поля, маски и сообщения валидации.
- Сохранить документ и убедиться, что запись появилась в таблице.

## 3) Отправка на согласование

- Открыть созданный документ.
- Нажать `Отправить на согласование`, выбрать маршрут/согласующих, подтвердить.
- Убедиться, что статус стал `На согласовании`, запись появилась в `В работе`.

## 4) Решение по согласованию

- Открыть документ из `На согласовании`.
- Проверить сценарии `Согласовать`, `На доработку`, `Отклонить` (минимум один за прогон).
- Проверить, что статус и история карточки обновились корректно.

## 5) Действия администратора

- Открыть `Админ панель`.
- Проверить просмотр компаний/сотрудников/маршрутов.
- Проверить одно неразрушающее действие (например, редактирование данных в форме без сохранения).

## 6) Негативные проверки

- Принудительно вызвать API-ошибку (невалидные данные или отключенный backend) и убедиться, что отображаются:
  - понятное сообщение,
  - кнопка `Повторить`,
  - fallback-действие (переход на связанный раздел).

## 7) Финальная проверка

- Пройти key pages: `Landing` -> `Мои документы` -> `В работе` -> `Карточка документа` -> `Админ панель`.
- Проверить empty/loading/error состояния.
- Проверить, что нет визуальных регрессий в таблицах на desktop и mobile-width.
